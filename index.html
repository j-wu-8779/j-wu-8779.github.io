Selected Machine Learning Projects

Music Genre Classification
Python, pandas, scikit-learn, PCA, KMeans, Gradient Boosting

Built an end-to-end multiclass classification pipeline using a dataset of 50,000 Spotify songs. Designed a leakage-free workflow with preprocessing, PCA, clustering-derived features, and Gradient Boosting. Achieved a final macro one-vs-rest AUC of 0.9341 and evaluated model behavior through ROC curves and feature importance analysis.

Diabetes Prediction Model Comparison
Python, scikit-learn

Compared Logistic Regression, Linear SVM, Decision Tree, and Random Forest models on a real health dataset. Used ROC AUC as the primary metric and analyzed feature importance through drop-one-feature testing. Observed how model performance depends on data structure rather than model complexity alone.
